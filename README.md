# Local_File_Server

Простая и легковесная утилита с графическим интерфейсом на Python для быстрой раздачи файлов в локальной сети. Позволяет в пару кликов поднять веб-сервер и расшарить директорию для других устройств (планшетов, смартфонов, ПК) через Wi-Fi или LAN без необходимости сложной настройки сети или доступа к интернету.

## ⚡ Особенности

* **Многопоточность:** Базируется на `ThreadingHTTPServer` — подключенные устройства скачивают файлы параллельно, не блокируя друг друга.
* **Умное определение IP:** Скрипт корректно находит IPv4-адрес устройства в сети роутера, игнорируя виртуальные адаптеры (Docker, WSL) даже без подключения к интернету.
* **Надежное хранение настроек:** Выбранная папка, порт и параметр автозапуска сохраняются в системную директорию Windows (`AppData\Roaming\LocalFileServer\settings.json`).
* **Стабильная работа без консоли:** Переопределен обработчик логов (`QuietHandler`), что предотвращает падение скомпилированного `.exe` файла из-за отсутствия стандартного вывода (stdout).

## 🚀 Быстрый старт (Для пользователей)

1. Скачайте файл `Local_File_Server.exe` из репозитория.
2. Запустите приложение. *(При первом запуске Windows может запросить разрешение брандмауэра — обязательно разрешите доступ для частных сетей).*
3. Выберите папку с файлами, которые хотите раздать.
4. Нажмите **Запустить сервер**.
5. Откройте сгенерированную ссылку (например, `http://192.168.1.33:8000`) в браузере на любом устройстве, подключенном к вашей Wi-Fi сети.

## 🛠 Использование исходного кода (Для разработчиков)

Программа написана на чистом Python 3 и использует встроенные библиотеки (`tkinter`, `http.server`, `threading`, `socket`), поэтому установка внешних зависимостей не требуется.

**Клонирование и запуск:**
bash
git clone [https://github.com/runtime-err/Local_File_Server.git](https://github.com/runtime-err/Local_File_Server.git)
cd Local_File_Server
python Local_File_Server.py


## 📦 Сборка в .exe
Для самостоятельной компиляции скрипта в один независимый исполняемый файл используется PyInstaller:

Bash
pip install pyinstaller
python -m PyInstaller --noconsole --onefile --icon=logo.ico Local_File_Server.py
Готовый файл появится в папке dist.
